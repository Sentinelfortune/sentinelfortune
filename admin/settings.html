About this admin app

This UI has no password login of its own — access is controlled entirely by Cloudflare Access at the edge, and independently re-verified by the Shop Worker on every request. If this app is reachable without an Access challenge, it is not deployed correctly — see CLOUDFLARE_SHOP_SETUP.md in the repository.
