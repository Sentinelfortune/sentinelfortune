{%- comment -%} Newsletter signup. There is no email backend yet. Rather than shipping a form that says "Thanks, you're subscribed!" into a void, this include has two states and picks between them from one config value: site.newsletter_endpoint == "" -> the honest state. No form. The visitor is told plainly that signup is not open yet and given the address that does reach a human. site.newsletter_endpoint set -> a real form that POSTs there. Turning the feature on is one line in _config.yml. Nothing here ever confirms a subscription that did not happen: the success message is only reachable through an actual HTTP 2xx from the configured endpoint. {%- endcomment -%}
